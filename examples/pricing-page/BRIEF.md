# 页面需求（两次运行使用完全相同的需求）

为一个名为 "Meridian" 的小型 API 监控产品做一个定价页面，输出单个自包含的 index.html
（内联 CSS，不引用任何外部资源，不联网）。

页面需要包含：
- 一个页头：产品名、一句话说明、一个主行动按钮
- 三档定价：Hobby（免费）、Team（每月 ¥199）、Enterprise（按需报价）
  每档包含：档位名、价格、4 条特性、一个行动按钮；Team 是推荐档位
- 一个简短的 FAQ，3 个问答
- 一个页脚：版权行 + 三个链接

约束：
- 中文界面
- 桌面优先，1280px 宽度下必须完整可看
- 不要使用任何图片或图标字体（没有网络）
